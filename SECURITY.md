# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately via [GitHub Security Advisories](https://github.com/sanjuthomas/log-forwarder-atc/security/advisories/new) or by opening a minimal issue asking for a private contact channel.

Include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Affected version(s)
- Any suggested fix, if you have one

We aim to acknowledge reports within a few business days and will coordinate disclosure once a fix is available.

## Scope

This policy covers the log-forwarder-atc application and its official Docker image. It does not cover third-party dependencies or deployments configured outside this repository.
